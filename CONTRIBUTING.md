# Contribution au projet

1. Créez une branche portant votre identifiant apprenant.
2. Travaillez dans vos propres fichiers SQL et livrables.
3. Utilisez des commits explicites : `feat: analyse CA mensuel`.
4. N'ajoutez aucun mot de passe, export sensible ou données personnelles.
5. Relisez les requêtes et le README avant d'ouvrir une Pull Request.
